# U-rent
This platform aims to bridge that gap by providing a digital space for renting items. It allows individuals to rent out items they own but don’t use regularly, such as large dishes, generators, tents, and event supplies. At the same time, it enables users to access these items at a fraction of the cost of purchasing them.
